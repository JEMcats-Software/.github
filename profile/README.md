## AI (Artificial Intelligence) policy
Some code in our repositories may have been generated partially by AI but we can guarantee that there was at a minimum somebody reviewing those requests and their outputs. Aditionally there will absolutely be somebody ensuring the code is secure. We believe in AI as tool, **NOT** a replacement and prompting should never be a job. We value our human contributers and you should too.
